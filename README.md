# MiniTorch

Educational deep learning scaffold organized by lesson.

## Layout

- `autograd/`: scalar values and reverse-mode autodiff
- `nn/`: neural network layers, activations, losses, and initialization
- `optim/`: optimizers and learning-rate scheduling
- `data/`: dataset loading utilities
- `training/`: training loop helpers and metrics
- `examples/`: runnable example scripts
- `train.py`: project entry point

## Run

```bash
python train.py
```
